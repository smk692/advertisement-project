# AD_RANK 광고 시스템 용어사전

AD_RANK 기반 광고 시스템 개발에 필요한 광고 관련 용어들을 정리한 사전입니다.

---

## 🎯 핵심 광고 용어

### AD_RANK (Advertisement Rank)
**광고 순위 점수**
- 광고의 노출 순위를 결정하는 핵심 점수
- 카테고리별로 계산되는 광고 품질 지표
- 본 프로젝트의 핵심 알고리즘

### CPC (Cost Per Click)
**클릭당 비용**
- 광고가 클릭될 때마다 광고주가 지불하는 금액
- 성과형 광고의 대표적인 과금 방식
- **새로운 계산 방식**: 정렬된 상품 순서에서 각 상품별로 바로 아래 상품의 AD_RANK / 본 상품의 클릭 전환율(%) + 1원

### CPM (Cost Per Mille)
**노출당 비용**  
- 광고가 1,000번 노출될 때마다 광고주가 지불하는 금액
- 브랜드 광고에서 주로 사용
- 예시: 1,000회 노출당 5,000원

### CPA (Cost Per Action/Acquisition)
**전환당 비용**
- 구매, 회원가입 등 목표 행동이 발생할 때마다 지불하는 금액
- 가장 성과 중심적인 과금 방식
- 예시: 구매 1건당 3,000원

---

## 📊 성과 측정 지표

### CTR (Click-Through Rate)
**클릭률**
- 노출 대비 클릭 비율 = (클릭 수 ÷ 노출 수) × 100
- 광고의 매력도와 관련성을 측정하는 핵심 지표
- 일반적으로 1~3% 수준

### CVR (Conversion Rate)  
**전환율**
- 클릭 대비 전환 비율 = (전환 수 ÷ 클릭 수) × 100
- 랜딩 페이지와 상품의 매력도 측정
- 업종별로 크게 상이 (1~10%)

### ROAS (Return on Ad Spend)
**광고 수익률**
- 광고비 대비 매출 비율 = 광고 기여 매출 ÷ 광고비 × 100
- 광고 효율성을 나타내는 최종 지표
- 예시: ROAS 300% = 광고비 1원당 3원의 매출

### CPC (Cost Per Click) - 실제 지표
**평균 클릭당 비용**
- 실제 발생한 총 광고비 ÷ 총 클릭 수
- 입찰가와 다를 수 있음 (경쟁 상황에 따라)

### eCPM (Effective Cost Per Mille)
**유효 노출당 비용**
- 실제 광고비를 1,000회 노출당 비용으로 환산한 값
- 다른 과금 방식과의 비교를 위해 사용

## 🎪 광고 영역 및 배치

### Placement
**광고 영역**
- 광고가 노출되는 위치나 지면
- 본 프로젝트: HOME, CATEGORY, PRODUCT_DETAIL, SEARCH

### Above the Fold
**스크롤 없이 보이는 영역**
- 페이지 로딩 시 스크롤 없이 바로 보이는 영역
- 높은 가시성으로 프리미엄 광고 영역

### Below the Fold  
**스크롤해야 보이는 영역**
- 사용자가 스크롤해야 볼 수 있는 영역
- 상대적으로 낮은 CTR

### Native Ad
**네이티브 광고**
- 콘텐츠와 자연스럽게 섞여 있는 광고 형태
- 사용자 경험을 해치지 않는 광고

### 광고 슬롯 (Ad Slot)
**광고 노출 위치**
- 1~10번 슬롯으로 구성된 광고 노출 위치
- 각 슬롯별로 다른 노출 비중과 성과 지표
- 확장 가능한 구조 (현재 10개, 추가 가능)

## 💰 입찰 및 경매

### Bid Price
**입찰가**
- 광고주가 특정 광고 노출 기회에 대해 제시하는 최대 지불 의향 금액
- 본 프로젝트의 최대입찰가 파라미터

### Floor Price
**최저 입찰가**
- 매체에서 설정하는 최소 입찰 금액
- 이보다 낮은 입찰은 참여 불가

### Winning Bid
**낙찰가**
- 경매에서 실제로 이긴 입찰가
- 실제 지불 금액과는 다를 수 있음

### Second Price Auction
**2가 경매**
- 최고가 입찰자가 이기지만 2번째 높은 가격을 지불
- 본 프로젝트의 Pricing 알고리즘 기반

💰 revenue_amount란?
- 정의: 해당 주문/전환에서 발생한 총 매출액 (주문 금액)
- 용도: 광고 성과 측정의 핵심 지표
- ROAS 계산: revenue_amount / 광고비용
- CVR 계산: 전환당 평균 수익
- 광고 효율성 분석: 어떤 광고가 더 높은 수익을 만드는지
- 예시: 노트북 1,200,000원 주문 → revenue_amount = 1200000

## 🎯 타겟팅

### Demographic Targeting
**인구통계학적 타겟팅**
- 연령, 성별, 지역 등 기본 정보 기반 타겟팅
- 본 프로젝트: target_gender, target_age_min/max

### Behavioral Targeting
**행동 타겟팅**
- 사용자의 과거 행동 패턴 기반 타겟팅
- 클릭, 구매, 검색 이력 활용

### Contextual Targeting
**맥락적 타겟팅**
- 현재 보고 있는 콘텐츠와 관련된 광고 노출
- 카테고리, 검색어 기반

### Retargeting
**리타겟팅**
- 이전에 접촉한 사용자를 다시 타겟팅
- 장바구니 이탈, 상품 조회 후 미구매 사용자 대상

## 🔍 데이터 및 분석

### Impression
**노출**
- 광고가 사용자에게 실제로 보여진 횟수
- 과금과 무관하게 측정되는 기본 지표

### Viewability
**뷰어빌리티**
- 광고가 실제로 사용자에게 보일 수 있는 상태
- IAB 기준: 50% 이상 영역이 1초 이상 노출

### Attribution
**어트리뷰션**
- 전환에 대한 광고의 기여도 측정
- 본 프로젝트: 24시간 클릭 기여도 모델

### Frequency
**노출 빈도**
- 동일 사용자에게 같은 광고가 노출된 횟수
- 과다 노출 방지를 위한 관리 필요

### Reach
**도달률**
- 광고를 본 순 사용자 수
- 중복 제거된 실제 도달 규모

## ⚙️ 기술 용어

### Ad Server
**광고 서버**
- 광고를 실제로 송출하는 시스템
- 본 프로젝트의 광고API에 해당

### DSP (Demand-Side Platform)
**수요측 플랫폼**
- 광고주를 위한 광고 구매 플랫폼
- AD_RANK 참여, 입찰 최적화 기능

### SSP (Supply-Side Platform)
**공급측 플랫폼**
- 매체를 위한 광고 판매 플랫폼
- 광고 인벤토리 관리 및 수익 최적화

### Ad Exchange
**광고 거래소**
- 광고 인벤토리가 거래되는 플랫폼
- 실시간 경매가 이루어지는 장소

### DMP (Data Management Platform)
**데이터 관리 플랫폼**
- 사용자 데이터 수집, 분석, 활용 플랫폼
- 타겟팅 고도화를 위한 데이터 허브

## 🧮 AD_RANK 알고리즘 관련 용어

### 카테고리별 AD_RANK 계산
**카테고리 기반 광고 점수**
- 각 광고 구좌에 카테고리별로 AD_RANK 계산
- 동일 카테고리 내에서 광고 간 경쟁
- 카테고리별 독립적인 점수 체계

### AD_RANK 내림차순 정렬
**점수 기반 순위 결정**
- 계산된 AD_RANK 점수를 기준으로 내림차순 정렬
- 높은 점수부터 낮은 점수 순으로 정렬
- 순위 결정의 기본 기준

### 상품 노출 순위 계산
**복합 기준 노출 순위**
- AD_RANK 높은 순으로 기본 정렬
- 노출 기준치 충족 여부 (1,000회 이상/이하)
- 구매 전환 여부 (1,000회 노출 동안 1회 이상 구매)
- 세 가지 기준을 종합한 최종 노출 순위

### 노출 기준치
**노출 수 기준**
- 해당 상품의 노출수가 1,000회 이상/이하 기준
- 1,000회 이상: 가산점 부여
- 1,000회 이하: 가산점 미부여

### 구매 전환 기준
**구매 성과 기준**
- 해당 상품의 노출 1,000회 동안 구매 1회 이상 여부
- 1회 이상: 가산점 부여
- 1회 미만: 가산점 미부여

### 상품별 노출 비중 계산
**점수 기반 비중 계산**
- 상품의 노출비중(%) = 상품의 AD_RANK 점수 / 전체 AD_RANK 점수 합계
- AD_RANK 기준 내림차순 정렬 상태에서 계산
- 노출 비중 상한 30% 제한

### 노출 비중 상한 제한
**단일 상품 노출 제한**
- 단일 상품의 노출 비중이 30%를 넘는 경우 최대 30%로 제한
- 초과된 비중은 하위 랭크 상품들에 재분배
- 재분배 기준: 각 상품의 원노출 비중 비율

### 슬롯별 노출 비중 계산
**위치별 노출 비중**
- 검색어/카테고리별로 1~10번 슬롯별 노출 비중 계산
- 최근 90일 데이터 기준
- 확장 가능한 구조 (현재 10개, 추가 가능)

### 랜덤 노출 비중 계산
**랜덤 노출 옵션**
- 전체 슬롯(1~10번)에 모든 상품 랜덤 노출
- 누적 노출수 1,000회 기준으로 데일리 계산
- 다양한 노출 전략 중 하나

### 클릭전환율 (Click-Conversion Rate)
**클릭 대비 전환율**
- 최근 1주일 기준으로 계산되는 전환율
- AD_RANK 계산의 핵심 요소
- CPC 계산에서 사용되는 핵심 지표

### Pacing
**페이싱**
- 예산을 계획적으로 소진하기 위한 조절 기법
- 하루 종일 고르게 광고 노출 유지

### Optimization
**최적화**
- 목표 지표 달성을 위한 자동 조정 과정
- 입찰가, 타겟팅, 예산 배분 등

### Machine Learning
**머신러닝**
- 데이터 기반 자동 학습 및 예측
- CTR/CVR 예측, 개인화 등에 활용

## 📊 본 프로젝트 특화 용어

### AD_RANK 계산 기간
- 클릭전환율 계산 기준: 최근 1주일
- 매일 갱신되는 실시간 데이터

### 방어값 (Default Value)
- CTR 0인 경우 임의로 부여하는 0.1점
- 추후 로직 고도화를 위한 임시 조치

### 지면별 AD_RANK 적용
- HOME, CATEGORY, PRODUCT_DETAIL, SEARCH
- 각 지면별로 독립적인 AD_RANK 계산

### 실험 키 (exp_key)
- A/B 테스트를 위한 실험 식별자
- 가격 실험, 알고리즘 실험 등에 사용

### 기여 매출
- 광고 클릭으로 인한 매출
- 24시간 내 주문, 세션 기반 어트리뷰션

### 광고 구좌
**광고 계정**
- 광고주별로 생성되는 광고 관리 단위
- 카테고리별 AD_RANK 계산의 기본 단위
- 캠페인, 상품, 예산 관리의 컨테이너

## 🔄 실시간 랭킹 관리 용어

### 캠페인 변경 이벤트
**캠페인 상태 변경**
- 캠페인 추가/수정/삭제 시 발생하는 이벤트
- 해당 캠페인의 모든 상품 관련 랭킹 재갱신 필요
- 실시간 AD_RANK 점수 업데이트 트리거

### 랭킹 재갱신 (Ranking Refresh)
**실시간 순위 업데이트**
- 캠페인 변경 시 해당 카테고리의 모든 상품 랭킹 재계산
- AD_RANK 점수, CPC, 노출 순위, 노출 비중 등 전체 재계산
- 실시간 시스템 안정성을 위한 필수 프로세스

### 캠페인 상태 관리
**캠페인 활성화/비활성화**
- 캠페인의 현재 운영 상태 관리
- 활성(ACTIVE), 일시중지(PAUSED), 종료(ENDED) 등 상태 구분
- 상태에 따른 랭킹 참여 여부 결정

## 💰 예산 관리 용어

### 캠페인 지출액 한도
**일일 예산 한도**
- 캠페인별로 설정된 일일 최대 지출 금액
- 한도 도달 시 캠페인 자동 일시중지
- 예산 초과 방지를 위한 안전장치

### 거래처 지갑 금액
**광고주 계정 잔액**
- 광고주가 충전한 광고비 잔액
- 잔액 소진 시 해당 거래처의 모든 캠페인 일시중지
- 시스템 안정성을 위한 예산 관리

### 예산 소진 감지
**실시간 예산 모니터링**
- 캠페인 지출액 한도 및 거래처 지갑 금액 실시간 추적
- 한도 도달 시 즉시 캠페인 상태 변경
- 랭킹에서 자동 제외 처리

### 일시중지 (PAUSED)
**캠페인 운영 중단**
- 예산 소진 또는 수동 중지로 인한 캠페인 운영 중단
- 일시중지 상태의 캠페인은 랭킹에서 제외
- 예산 충전 또는 수동 재개 시 활성화 가능

### 자동 재개 (Auto Resume)
**예산 충전 시 자동 활성화**
- 거래처 지갑 금액 충전 시 일시중지된 캠페인 자동 재개
- 캠페인 지출액 한도 리셋 시 자동 활성화
- 사용자 개입 없이 자동화된 예산 관리
