# AD_RANK 광고 엔진 요구사항 정리

## 📋 프로젝트 개요

### 개발 배경
- **타임라인**: 2023.3Q 초 Citrus Ad 오픈소스 도입 → 2025.4Q 목표 자체 AD_RANK 기반 광고 시스템 구축
- **목적**: 회사 자체 수수료 구조 개선, 개발 대기시간 단축, Citrus Ad 기본 관리 기능 대체
- **요구사항**: Citrus Ad와 동일한 구성 및 구현, 기존 성과 이상의 AD_RANK 엔진 구축
- **새로운 방향**: 복잡한 RTB에서 정교하고 실용적인 AD_RANK 시스템으로 전환

### 핵심 구성요소 (1차 개발 범위)
- **AD_RANK 엔진 (광고 API + Worker + Flink)**
- **어드민 시스템 = 판매자어드민 캠페인, 거래처 및 관리 시스템**
- **확장성**: 가격 실험/개인화 대응

## ⚙️ AD_RANK 엔진 알고리즘 요구사항

### 1. 카테고리별 AD_RANK 계산 🎯

> **📝 쉽게 말하면**: 각 광고 구좌에 카테고리별로 AD_RANK를 계산하는 방법이에요. 마치 각 반별로 시험 점수를 매기는 것과 같아요!

**목적:** 각 광고 구좌에 카테고리별로 AD_RANK 점수 계산

#### 1-1. 카테고리별 독립 계산

**계산 방식:**
- 각 광고 구좌별로 카테고리별 독립적인 AD_RANK 계산
- 동일 카테고리 내에서 광고 간 경쟁
- 카테고리별 독립적인 점수 체계

#### 1-2. AD_RANK 계산 공식

**AD_RANK 공식:**
```
AD_RANK = 최대 기대매출(최대 입찰가) × 클릭 전환율(%)
```

**계산 기준:**
- **클릭전환율**: 최근 1주일 기준
- **CTR 0인 경우**: 임의로 0.1점 부여 (추후 로직 고도화 필요)
- **갱신 주기**: 매일 갱신

#### 1-3. 광고 타입별 AD_RANK 계산

**키워드 광고:**
- 키워드 기준으로 비딩 대상 상품들을 모아서 랭크 계산

**카테고리 광고:**
- 광고 상품에 설정된 모든 3차/4차 카테고리 속성을 기준으로 비딩
- 어드민에 등록된 상품의 '카테고리', '노출용 4차 카테고리' 기준으로 해당 카테고리에 matching되는 지면에 노출

**상품상세 광고:**
- 광고 등록한 3차 카테고리 기준으로 해당 카테고리에 비딩한 모든 상품 대상으로 랭크 계산
- 상품 상세 별로, 그 상품의 3차/4차 카테고리 속성을 기반으로 카테고리에 속한 모든 광고 상품들을 수집한 후, Ad rank에 따라 정렬하여 상위 10개 상품을 노출

**홈 광고:**
- 강아지/고양이 구분으로 랭크 계산

#### 1-4. AD_RANK 계산 대상 선별 기준

**노출 기준치 확인:**
- **최근일부터 과거 누적 노출수 1,000회 도달 시점**을 먼저 확인
- 특정 기간(최근 한달, 60일 등) 기준으로 하면 광고 진행 기간이 제각각인 상품들의 노출수에서 차이가 발생할 수 있기 때문
- **과거 누적 노출수가 1,000 미만인 경우**는 총 노출수를 기준으로 계산
- **데일리 계산 필요**

**계산 대상:**
- (카테고리) 전체 구좌에 포함된 모든 상품이 몇개인지 확인
- 누적 노출수 1,000회 이상 도달한 상품들 대상으로 AD_RANK 계산

**실제 계산 예시:**

**카테고리: 노트북**
- **광고 A (삼성)**: AD_RANK = 25점
- **광고 B (LG)**: AD_RANK = 20점
- **광고 C (애플)**: AD_RANK = 15점

**카테고리: 스마트폰**
- **광고 D (삼성)**: AD_RANK = 30점
- **광고 E (애플)**: AD_RANK = 28점

> **💡 핵심**: 각 카테고리별로 독립적으로 계산되어 카테고리 간 간섭이 없습니다!

### 2. CPC 계산 💰

> **📝 쉽게 말하면**: 광고 가격을 정하는 방법이에요. 바로 아래 순위의 AD_RANK를 본인의 클릭전환율로 나누고 1원을 더하는 방식이에요!

**목적:** 정렬된 상품 순서에서 각 상품별 CPC 산정

#### 2-1. CPC 계산 공식

**CPC 계산 공식:**
```
CPC = (바로 아래 상품의 AD_RANK / 본 상품의 클릭 전환율(소수점)) + 1원
```

> **🧒 쉬운 설명**: 지불가격 = (다음 순위 점수 ÷ 내 전환율) + 1원
> **💡 주의**: 클릭전환율은 퍼센트(%)가 아닌 소수점으로 계산 (예: 2.5% → 0.025)

#### 2-2. 실제 계산 예시

**노트북 카테고리 (AD_RANK 내림차순 정렬):**

**1등: 광고 A (삼성)**
- AD_RANK = 25점
- 클릭전환율 = 2.5% = 0.025
- **CPC = (20 / 0.025) + 1 = 801원**

**2등: 광고 B (LG)**
- AD_RANK = 20점
- 클릭전환율 = 3.0% = 0.03
- **CPC = (15 / 0.03) + 1 = 501원**

**3등: 광고 C (애플)**
- AD_RANK = 15점
- 클릭전환율 = 2.0% = 0.02
- **CPC = 15원** (다음 순위 없음, 최대 입찰가 사용)

> **💡 분석**: 높은 순위일수록 상대적으로 낮은 CPC를 지불하게 되어 있어요!

### 3. 상품 노출 순위 계산 📊

> **📝 쉽게 말하면**: AD_RANK 높은 순으로 기본 정렬한 후, 추가 기준으로 최종 노출 순위를 결정하는 방법이에요!

**목적:** AD_RANK 높은 순으로 기본 정렬 후, 추가 기준으로 최종 노출 순위 결정

#### 3-1. 노출 기준치 충족 여부

**기준:**
- 해당 상품의 노출수가 1,000회 이상/이하
- **1,000회 이상**: 가산점 부여
- **1,000회 이하**: 가산점 미부여

#### 3-2. 구매 전환 여부

**기준:**
- 해당 상품의 노출 1,000회 동안 구매 1회 이상 여부
- **1회 이상**: 가산점 부여
- **1회 미만**: 가산점 미부여

#### 3-3. 최종 노출 순위 결정

**최종 노출 순위 공식:**
```
최종_노출_순위 = AD_RANK_기본_순위 + 노출_기준치_가산점 + 구매_전환_가산점
```

**실제 적용 예시 (PDF 기준):**

**기본 AD_RANK 순위:**
1. 광고 b (45점)
2. 광고 a (51점)
3. 광고 c (42점)
4. 광고 e (23점)
5. 광고 d (37점)
6. 광고 f (19점)
7. 광고 g (0.1점)

**가산점 적용 후:**
- **광고 b**: 45점 + 노출기준치(✓) + 구매전환(✓) = **47점** → **1순위**
- **광고 a**: 51점 + 노출기준치(✓) + 구매전환(✗) = **52점** → **3순위**
- **광고 c**: 42점 + 노출기준치(✗) + 구매전환(✓) = **43점** → **5순위**
- **광고 e**: 23점 + 노출기준치(✓) + 구매전환(✗) = **24점** → **4순위**
- **광고 d**: 37점 + 노출기준치(✓) + 구매전환(✓) = **39점** → **2순위**
- **광고 f**: 19점 + 노출기준치(✗) + 구매전환(✓) = **20점** → **6순위**
- **광고 g**: 0.1점 + 노출기준치(✗) + 구매전환(✗) = **0.1점** → **7순위**

**최종 노출 순위:**
1. **광고 b (47점) - 19.35%**
2. **광고 d (39점) - 23.49%**
3. **광고 a (52점) - 10.59%**
4. **광고 e (24점) - 20.73%**
5. **광고 c (43점) - 17.04%**
6. **광고 f (20점) - 8.75%**
7. **광고 g (0.1점) - 0.05%**

> **💡 핵심**: AD_RANK가 높아도 노출 순위가 낮을 수 있어요. 추가 기준들이 중요한 역할을 합니다!

### 4. 상품별 노출 비중 계산 ⚖️

> **📝 쉽게 말하면**: AD_RANK 점수 기반으로 각 상품이 얼마나 많이 노출될지 정하는 방법이에요!

**목적:** AD_RANK 점수 기반으로 상품별 노출 비중 계산

#### 4-1. 노출 비중 계산 공식

**노출 비중 계산 공식:**
```
상품의 노출비중(%) = 상품의 AD_RANK 점수 / 전체 AD_RANK 점수 합계
```

#### 4-2. 실제 계산 예시

**전체 AD_RANK 점수 합계: 60점**

- **광고 A**: 25점 → **노출비중 = 25/60 = 41.67%**
- **광고 B**: 20점 → **노출비중 = 20/60 = 33.33%**
- **광고 C**: 15점 → **노출비중 = 15/60 = 25.00%**

#### 4-3. 노출 비중 상한 제한

**제한 규칙:**
- 단일 상품의 노출 비중이 30%를 넘는 경우 최대 30%로 제한
- 초과된 비중은 하위 랭크 상품들에 재분배
- 재분배 기준: 각 상품의 원노출 비중 비율

**재분배 예시:**

**원래 노출 비중:**
- 광고 A: 41.67% (30% 초과)
- 광고 B: 33.33%
- 광고 C: 25.00%

**제한 적용 후:**
- 광고 A: **30.00%** (11.67% 초과분 제거)
- 광고 B: 33.33% + (11.67% × 33.33%/(33.33%+25.00%)) = **39.99%**
- 광고 C: 25.00% + (11.67% × 25.00%/(33.33%+25.00%)) = **30.01%**

> **🎯 목적**: 한 상품이 너무 많이 노출되는 것을 방지하여 다양한 상품이 노출될 기회를 제공합니다!

### 5. 슬롯별 노출 비중 계산 🎯

> **📝 쉽게 말하면**: 검색어/카테고리별로 1~10번 슬롯에 각각 얼마나 많은 광고를 보여줄지 정하는 방법이에요!

**목적:** 검색어/카테고리별로 1~10번 슬롯별 노출 비중 계산

#### 5-1. 슬롯 구성

**슬롯 구조:**
- **1~10번 슬롯**: 현재 최대 10개 슬롯
- **확장 가능**: 추가 슬롯 확장 가능한 구조
- **데이터 기준**: 최근 90일 데이터 기준

#### 5-2. 슬롯별 노출 비중 예시

**노트북 카테고리 슬롯별 비중:**
- **1번 슬롯**: 30%
- **2번 슬롯**: 23%
- **3번 슬롯**: 19%
- **4번 슬롯**: 14%
- **5번 슬롯**: 9%
- **6번 슬롯**: 5%

**슬롯별 노출 비중 계산 예시 (PDF 기준):**

**상품별 노출 비중:**
- 상품 C: 20.00%
- 상품 A: 33.33%
- 상품 B: 26.67%
- 상품 E: 6.67%
- 상품 D: 13.33%

**슬롯별 노출 비중:**
- 슬롯 1: 33.33%
- 슬롯 2: 26.67%
- 슬롯 3: 20.00%
- 슬롯 4: 13.33%
- 슬롯 5: 6.67%

**최종 노출 분배 (5000회 기준):**
- 슬롯 1: 1,667회 (C: 1,167회, A: 500회)
- 슬롯 2: 1,333회 (A: 1,000회, B: 333회)

> **💡 특징**: 상위 슬롯일수록 높은 노출 비중을 가지며, 사용자 주목도가 높은 위치입니다!

### 6. 랜덤 노출 비중 계산 🎲

> **📝 쉽게 말하면**: 전체 슬롯(1~10번)에 모든 상품을 랜덤으로 노출하는 방법이에요!

**목적:** 전체 슬롯(1~10번)에 모든 상품 랜덤 노출

#### 6-1. 랜덤 노출 옵션

**랜덤 노출 방식:**
- **옵션 1**: 전체 슬롯(1~10번)에 모든 상품 랜덤 노출
- **옵션 2**: 전체 슬롯(1~10번) 중 6~10번 슬롯에서만 랜덤 노출
  - 1~5번 슬롯은 상위 순위 상품들로 고정
  - 랜덤 시간동안 노출 순위 1~5위 상품들은 6~10번 슬롯 미노출

**계산 기준:**
- 누적 노출수 1,000회 기준으로 데일리 계산
- **랜덤 시간 분배**: 24시간을 100분 단위로 쪼개서 각 100분마다 랜덤 시간 할당
- **시간 분산**: 매 시간(60분)마다 10분 동안은 랜덤 노출 시간으로 분산

#### 6-2. 랜덤 노출 비중 예시

**노출 비중 분배:**
- **AD_RANK 기준**: 60%
- **랜덤 노출**: 40%

**신규 광고 가산점:**
- 신규 광고 상품은 광고 시작 후 7일간 Ad Rank 점수에 일정한 가산점 부여
- 노출 순위 상승을 통한 신규 상품 지원

> **🎯 목적**: AD_RANK 기반 노출과 랜덤 노출을 조합하여 다양한 상품이 노출될 기회를 제공합니다!

#### 6-3. 랜덤 노출 개발 고려사항

**개발 난이도:**
- **옵션 1 vs 옵션 2**: 개발 난이도 차이 확인 필요
- **시간 분산 로직**: 초단위로 랜덤 시간 배분 가능성 검토
- **신규 광고 지원**: 7일간 가산점 부여 로직 구현

**확인 필요 사항:**
- 슬롯별 노출 로직 확인
- 랜덤 노출 로직의 구체적인 구현 방식
- 신규 광고 가산점 부여 방식

### 7. 통합 알고리즘 흐름 🔄

#### 7-1. 전체 시스템 흐름

```
STEP 1: 광고 요청 수신
        → 카테고리별 요청 분류
        → 카테고리별 AD_RANK 계산

STEP 2: AD_RANK 내림차순 정렬
        → CPC 계산
        → 상품 노출 순위 계산

STEP 3: 상품별 노출 비중 계산
        → 노출 비중 상한 제한 (30%)
        → 초과분 재분배

STEP 4: 슬롯별 노출 비중 적용
        → 1~10번 슬롯별 비중 계산
        → 최근 90일 데이터 기준

STEP 5: 랜덤 노출 처리
        → 전체 슬롯 랜덤 노출
        → 최종 광고 할당

STEP 6: 광고 노출
        → Tracking API에 impression 이벤트 전송
        → 성과 데이터 수집
```

#### 7-2. 상세 알고리즘 코드

```
// 1단계: 카테고리별 AD_RANK 계산
FOR 각 카테고리별로:
    FOR 각 광고 IN 해당_카테고리_광고들:
        AD_RANK_계산(광고)
    
    // 2단계: AD_RANK 내림차순 정렬
    AD_RANK_순위리스트 = 정렬(해당_카테고리_광고들, AD_RANK_내림차순)
    
    // 3단계: CPC 계산
    FOR i = 1 TO AD_RANK_순위리스트.length:
        IF i < AD_RANK_순위리스트.length:
            CPC[i] = (AD_RANK[i+1] / 클릭전환율[i]) + 1
        ELSE:
            CPC[i] = 최대입찰가[i]
    
    // 4단계: 상품 노출 순위 계산
    FOR 각 광고 IN AD_RANK_순위리스트:
        노출_기준치_가산점 = 노출수 >= 1000 ? 1 : 0
        구매_전환_가산점 = 구매수 >= 1 ? 1 : 0
        최종_점수 = AD_RANK + 노출_기준치_가산점 + 구매_전환_가산점
    
    // 5단계: 상품별 노출 비중 계산
    전체_AD_RANK_합계 = SUM(AD_RANK_순위리스트)
    FOR 각 광고 IN AD_RANK_순위리스트:
        원래_노출비중 = AD_RANK / 전체_AD_RANK_합계
        IF 원래_노출비중 > 30%:
            노출비중 = 30%
            초과분 = 원래_노출비중 - 30%
            하위_상품들에_재분배(초과분)
        ELSE:
            노출비중 = 원래_노출비중
    
    // 6단계: 슬롯별 노출 비중 적용
    슬롯별_노출비중 = 최근_90일_데이터_기준_계산()
    
    // 7단계: 랜덤 노출 처리
    랜덤_노출_비중 = 40%
    AD_RANK_노출_비중 = 60%
```

### 10. 실시간 랭킹 관리 시스템 🔄

> **📝 쉽게 말하면**: 캠페인이 변경되거나 예산이 소진될 때 실시간으로 랭킹을 업데이트하는 시스템이에요!

**목적:** 캠페인 변경 및 예산 소진에 따른 실시간 랭킹 관리

#### 10-1. 캠페인 변경 시 랭킹 재갱신

**이벤트 트리거:**
- 캠페인 추가/수정/삭제 시 실시간 이벤트 발생
- 해당 캠페인의 모든 상품 관련 랭킹 재갱신 필요

**재갱신 프로세스:**
```
// 캠페인 변경 이벤트 발생 시
IF 캠페인_변경_이벤트_발생:
    // 1단계: 영향받는 카테고리 식별
    영향받는_카테고리들 = 해당_캠페인_상품들의_카테고리
    
    // 2단계: 각 카테고리별 랭킹 재계산
    FOR 각 카테고리 IN 영향받는_카테고리들:
        // AD_RANK 점수 재계산
        FOR 각 광고 IN 해당_카테고리_광고들:
            IF 광고.캠페인ID == 변경된_캠페인ID:
                AD_RANK_재계산(광고)
        
        // 전체 랭킹 재정렬
        AD_RANK_순위리스트_재정렬(해당_카테고리)
        
        // CPC 재계산
        CPC_재계산(해당_카테고리)
        
        // 노출 순위 재계산
        노출_순위_재계산(해당_카테고리)
        
        // 노출 비중 재계산
        노출_비중_재계산(해당_카테고리)
    
    // 3단계: 캐시 업데이트
    랭킹_캐시_업데이트(영향받는_카테고리들)
    
    // 4단계: 이력 기록
    랭킹_재갱신_이력_저장(재갱신_정보)
```

**실제 적용 예시:**

**캠페인 수정 시나리오:**
1. **삼성 노트북 캠페인 입찰가 변경**: 1000원 → 1200원
2. **영향받는 카테고리**: 노트북 카테고리
3. **재갱신 프로세스**:
   - 삼성 노트북 AD_RANK 재계산: 25점 → 30점
   - 전체 노트북 카테고리 랭킹 재정렬
   - CPC 재계산 (모든 상품)
   - 노출 순위 및 비중 재계산
   - 캐시 업데이트

> **💡 핵심**: 캠페인 변경 시 해당 카테고리의 모든 상품 랭킹이 실시간으로 재계산됩니다!

#### 10-2. 예산 소진 시 캠페인 일시중지

**예산 모니터링 시스템:**
- 캠페인 지출액 한도 및 거래처 지갑 금액 실시간 추적
- 한도 도달 시 즉시 캠페인 상태 변경

**일시중지 프로세스:**
```
// 실시간 예산 모니터링
WHILE TRUE:
    FOR 각 캠페인 IN 활성_캠페인들:
        // 1단계: 캠페인 지출액 한도 체크
        IF 캠페인.일일_지출액 >= 캠페인.일일_한도:
            캠페인_일시중지(캠페인ID)
            랭킹에서_제외(캠페인ID)
            알림_발송(캠페인_소유자, "예산 한도 도달")
        
        // 2단계: 거래처 지갑 금액 체크
        거래처ID = 캠페인.소유_거래처ID
        IF 거래처.지갑_잔액 <= 0:
            // 해당 거래처의 모든 캠페인 일시중지
            FOR 각 캠페인 IN 거래처.캠페인들:
                캠페인_일시중지(캠페인ID)
                랭킹에서_제외(캠페인ID)
            알림_발송(거래처, "지갑 잔액 소진")
    
    // 3단계: 예산 충전 시 자동 재개
    FOR 각 거래처 IN 일시중지_거래처들:
        IF 거래처.지갑_잔액 > 0:
            FOR 각 캠페인 IN 거래처.일시중지_캠페인들:
                IF 캠페인.일일_지출액 < 캠페인.일일_한도:
                    캠페인_재개(캠페인ID)
                    랭킹에_재포함(캠페인ID)
    
    SLEEP(1분) // 1분마다 체크
```

**자동 재개 로직:**
```
// 예산 충전 시 자동 재개
IF 거래처_지갑_충전_이벤트:
    FOR 각 캠페인 IN 거래처.일시중지_캠페인들:
        IF 캠페인.일일_지출액 < 캠페인.일일_한도:
            캠페인_상태 = "ACTIVE"
            랭킹_재갱신_트리거(캠페인.카테고리들)
```

**실제 적용 예시:**

**예산 소진 시나리오:**
1. **LG 노트북 캠페인**: 일일 한도 50,000원, 현재 지출 50,000원
2. **자동 일시중지**: 캠페인 상태 → PAUSED
3. **랭킹에서 제외**: 노트북 카테고리 랭킹에서 LG 제외
4. **재계산**: 나머지 상품들의 랭킹, CPC, 노출 비중 재계산
5. **알림 발송**: LG 담당자에게 "예산 한도 도달" 알림

**예산 충전 시나리오:**
1. **LG 거래처**: 지갑 잔액 0원 → 100,000원 충전
2. **자동 재개**: LG 노트북 캠페인 상태 → ACTIVE
3. **랭킹 재포함**: 노트북 카테고리 랭킹에 LG 재포함
4. **전체 재계산**: 노트북 카테고리 전체 랭킹 재계산

> **🎯 목적**: 예산 소진 시 즉시 캠페인을 중지하여 예산 초과를 방지하고, 충전 시 자동으로 재개하여 서비스 연속성을 보장합니다!
