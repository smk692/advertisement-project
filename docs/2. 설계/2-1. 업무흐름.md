# AD_RANK 광고 시스템 - 업무 플로우

## 🚀 광고 서비스 전체 업무 플로우

### 🔄 시스템 분리 구조
- **커머스 시스템**: 사용자 인터페이스, 광고 노출, 클릭 이벤트 발생, 구매 및 결제 처리
- **판매자 어드민**: 캠페인 관리, 거래처 관리, 승인 처리
- **AD_RANK 시스템 + Worker**: 광고 조회 요청 처리, 클릭이벤트 처리, AD_RANK 로직 처리
- **엘라스틱서치**: O(1) 랭킹 조회, 병렬 처리 지원, 하이브리드 아키텍처 (15분 배치 + 실시간 이벤트)

### 📋 비즈니스 프로세스 개요
1. **광고주 온보딩**: 회원가입 → 승인 → 잔액충전
2. **캠페인 설정**: 등록 → 심사 → 활성화 → 엘라스틱서치 인덱스 업데이트
3. **광고 서비스**: O(1) 랭킹 조회 → 노출 → 클릭 → 전환 → 정산
4. **성과 관리**: 모니터링 → 최적화 → 리포트


### 2️⃣ **캠페인 등록 및 승인 프로세스**

```mermaid
    participant F as Flink
```

### 3️⃣ **실제 광고 서비스 플로우 (O(1) 조회)**

```mermaid
sequenceDiagram
    participant U as 일반 사용자
    participant C as 커머스 시스템
    participant A as AD_RANK 시스템
    participant ES as 엘라스틱서치
    participant F as Flink
    
    Note over U,F: 시스템 분리 구조<br/>커머스: 노출/클릭/결제 담당<br/>AD_RANK+엘라스틱서치: O(1) 조회/이벤트처리/로직 담당
    
    U->>C: 1. 페이지 방문<br/>홈/카테고리/상품상세
    C->>A: 2. 광고 조회 요청<br/>deviceID, placement, category, searchterm, maxAds
    A->>ES: 3. O(1) 랭킹 조회<br/>엘라스틱서치 인덱스에서 즉시 조회
    ES->>A: 4. 랭킹 데이터 응답<br/>AD_RANK, CPC, 노출 순위, 노출 비중
    A->>C: 5. 광고 응답<br/>노출할 광고 데이터
    C->>U: 6. 광고 노출<br/>커머스 사이트에서 표시
    
    Note over U,C: 클릭은 커머스에서 발생
    
    U->>C: 7. 광고 클릭<br/>커머스 사이트 내에서
    C->>A: 8. 클릭 이벤트 전송<br/>ad_ID, 클릭 시간
    A->>F: 9. ad-events 토픽 발행<br/>Worker 즉시 잔액 차감
    A->>C: 10. 클릭 처리 완료<br/>차감 성공 응답
    C->>U: 11. 상품 페이지 이동<br/>광고 상품 상세 페이지
    
    Note over U,C: 구매 및 결제는 커머스에서 처리 (24시간 내)
    
    U->>C: 12. 구매 및 결제 완료<br/>상품 구매 + 결제 처리
    C->>C: 13. 주문 확정<br/>내부 결제 처리 완료
    C->>A: 14. order.completed 토픽 발행<br/>구매 정보 + device_id 매칭
    A->>F: 15. Flink 전환 매칭 Statement<br/>24시간 윈도우 + ad-events JOIN
    F->>A: 16. Flink 성과 집계 Statement<br/>5분 윈도우 클릭전환율 → 엘라스틱서치 업데이트
```

### 🔄 **실시간 랭킹 관리 플로우**

```mermaid
sequenceDiagram

    participant ES as 엘라스틱서치
    
    Note over A,ES: 캠페인 변경 시 실시간 랭킹 재갱신

    W->>ES: 5. 엘라스틱서치 인덱스 업데이트<br/>해당 카테고리 랭킹 데이터 갱신
    ES->>AS: 6. 업데이트 완료<br/>실시간 랭킹 조회 준비
```

### 💰 **예산 소진 시 자동 관리 플로우 (실시간 처리)**

```mermaid
sequenceDiagram

            W->>W: 3. CPC/노출비중 재계산<br/>영향받는 상품들의 랭킹 즉시 재계산

            W->>ES: 7. 즉시 Active 인덱스에서 제외<br/>해당 거래처 전체 캠페인 즉시 제거
            W->>W: 8. CPC/노출비중 재계산<br/>영향받는 모든 상품들의 랭킹 즉시 재계산
            W->>ES: 9. 재계산된 랭킹 즉시 반영<br/>Active 인덱스에 즉시 업데이트
            W->>A: 10. 알림 발송<br/>"지갑 잔액 소진" 알림
        end
    end
```
