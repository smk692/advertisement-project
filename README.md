# AD_RANK 광고 시스템 (Adaptive Ranking Advertisement System)

## 프로젝트 개요
커머스 플랫폼과 연동된 AD_RANK 기반 광고 시스템입니다. 카테고리별 독립적인 랭킹 계산과 적응형 조회 전략을 통해 광고 노출부터 클릭, 구매까지의 전체 여정을 추적하고 실시간으로 광고 성과를 최적화합니다.

### 🔄 시스템 분리 구조
- **커머스 시스템**: 사용자 인터페이스, 광고 노출, 클릭 이벤트 발생, 구매 및 결제 처리
- **광고 시스템**: AD_RANK 계산, 적응형 조회 처리, 잔액 관리, 성과 집계

### ⚡ 성능 목표
- **전체 평균 응답시간**: < 5ms
- **Elasticsearch O(1) 조회**: < 3ms (1000개 이상 상품)
- **Redis 캐시 조회**: < 3ms (100-1000개 상품)
- **실시간 계산**: < 10ms (100개 미만 상품)
- **혼합 처리량**: 6000 QPS
- **캐시 히트율**: 85% 이상

### 🎯 주요 기능
- **적응형 조회 전략**: 데이터 크기에 따른 최적 조회 방식 자동 선택
- **카테고리별 독립 랭킹**: 각 카테고리별 독립적인 AD_RANK 계산
- **실시간 잔액 관리**: 클릭 시 즉시 CPC 차감
- **통합 성과 추적**: 노출 → 클릭 → 구매 전환 매칭 (24시간 윈도우)
- **하이브리드 아키텍처**: Active + Temp 인덱스 + Alias 교체
- **Flink 통합 처리**: 단일 태스크로 AD_RANK 계산 + 클릭 처리 + 전환 처리

## 시스템 아키텍처

### 🏗️ 핵심 컴포넌트
1. **광고 API 서버**
   - 커머스 시스템에서 광고 조회 요청 처리 (< 5ms 응답)
   - 적응형 조회 전략 (실시간 계산/Redis/Elasticsearch)
   - 광고주 캠페인 관리 인터페이스
   - 실시간 잔액 체크 및 차감

2. **Flink 통합 처리 엔진**
   - **AD_RANK 계산**: 캠페인 등록/수정 시 점수 계산 후 Elasticsearch 저장
   - **클릭 처리**: 실시간 잔액 차감 및 성과 업데이트
   - **전환 처리**: 24시간 윈도우 내 클릭-구매 매칭
   - **실시간 집계**: CTR, CVR, ROAS 계산
   - 단일 태스크로 모든 스트림 통합 처리

3. **Elasticsearch 랭킹 엔진**
   - **적응형 조회**: 데이터 크기별 최적 조회 방식 선택
   - **하이브리드 아키텍처**: Active + Temp 인덱스 + Alias 교체
   - **실시간 업데이트**: 예산/잔액 소진 시 즉시 반영
   - **배치 업데이트**: 일반 변경사항 15분마다 반영

4. **Redis 캐시 시스템**
   - `ad_rank:{placement}:{category}`: 중간 규모 데이터 랭킹 캐시
   - `balance:{advertiser_id}`: 실시간 잔액 정보
   - `budget:{campaign_id}:{date}`: 일일 예산 사용 현황
   - `metrics:ctr:{product_id}`: 5분 윈도우 CTR/CVR

5. **배치 처리 시스템**
   - **AD_RANK 랭킹 업데이트 파이프라인**: 캠페인 변경 시 즉시 실행
   - **일일 데이터 처리 파이프라인**: 매일 자정 일일집계 및 새벽 성과 요약
   - **독립 실행 배치**: 카테고리 통계(12시간), 데이터 정리(1시간)

6. **Kafka 메시지 큐**
   - `campaign-events`: 캠페인 등록/수정 이벤트
   - `ad-events`: 클릭 이벤트 스트림
   - `order.completed`: 주문 완료 이벤트

### 📊 업무 플로우
1. **광고주 온보딩** : 회원가입 → 심사 → 승인 → 잔액충전
2. **캠페인 설정** : 등록 → 심사 → 활성화
3. **광고 서비스** : 노출 → 클릭 → 전환 → 정산
4. **성과 관리** : 모니터링 → 최적화 → 리포트

## 팀 구성 및 역할

### 👥 개발팀 구성
- **API 개발팀**: 광고 조회 API (3-5ms 최적화), 캠페인 관리, Redis 캐시 처리
- **Flink 개발팀**: 통합 스트림 처리 (RTB 계산 + 클릭 처리 + 전환 매칭)
- **Worker 개발팀**: 성과 리포트, 배치 정산, 데이터 동기화

### 🎯 핵심 최적화 전략
- **Cache First**: 95% Cache Hit로 초고속 응답
- **Stream Unification**: Flink 단일 태스크로 비용 최적화
- **Smart Memory**: 실시간 데이터만 Redis 캐시
- **Real-time Processing**: 클릭-전환 매칭 24시간 윈도우

### 💡 최신 개선사항
- **ERD 다이어그램**: 시각적 데이터 모델링으로 테이블 관계 명확화
- **수익률 추적**: revenue_amount 필드로 정확한 ROAS 계산
- **정책 시나리오**: 주문 취소, 중복 주문 등 예외 상황 처리 방안 정립
